# Portfolio

Personal site for a senior mobile engineer. Built with TypeScript, React, and Tailwind on Next.js.

## Edit your content

Name, work, milestones, experience, and links live in [`src/content/profile.ts`](src/content/profile.ts). Screenshots in `public/` are cropped from App Store and Google Play listings.

## Run it

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
```

## Live site

Pushes to `main` publish a static export with GitHub Pages:

https://d-mick.github.io/My-Portfolio/

In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions**. The repository needs to be public for the free Pages plan.
